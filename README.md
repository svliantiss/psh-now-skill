# This repository has moved

The psh.now skill now ships from the main repository, so there is one place to install from and
one place to change:

**https://github.com/passy-ai/psh-now** (the skill lives in `skills/psh-now/`)

```bash
npx skills add passy-ai/psh-now -g -y
curl -fsSL https://psh.abslm.nl/install.sh | bash   # no npm, no git, no access needed
```

This repository is archived and will not be updated. Its history stays available, and GitHub
redirects the old URL here, so install lines already printed in old transcripts keep working.
